================================================================================
PANDUAN UPLOAD GITHUB - ALFA HISTORY WEB (VERSI 1.8.2)
================================================================================

Folder ini berisi 15 berkas produksi siap pakai untuk diunggah ke root repositori GitHub:

DAFTAR BERKAS:
1.  404.html          -> Pengalihan SPA & routing URL bersih /admin
2.  admin.html        -> Panel admin pengelolaan konten & konfigurasi AI
3.  CHANGELOG.txt     -> Catatan riwayat pembaruan versi 1.8.2
4.  CNAME             -> Domain custom alfahistory.web.id
5.  config.js         -> Konfigurasi Firebase / Web
6.  defaults.json     -> Data sejarah (32 koordinat dunia yang telah dikalibrasi)
7.  detail.html       -> Halaman artikel tokoh & peristiwa (potret mentok atas)
8.  favicon.ico       -> Ikon browser format ICO (transparan)
9.  favicon.svg       -> Ikon vektor emas-obsidian tajam
10. i18n.js           -> Mesin multibahasa & penelusuran semantik akurat
11. i18n_ar.json      -> Paket bahasa Arab
12. i18n_en.json      -> Paket bahasa Inggris
13. index.html        -> Halaman utama (Atlas interaktif, dropdown rapi, un-rounded UI)
14. sources_data.js   -> Rujukan primer sejarah Islam
15. track.js          -> Skrip analitik

CARA UNGGAH KE GITHUB:
1. Buka repositori GitHub alfahistory.web.id di browser.
2. Drag & drop seluruh 15 berkas di atas langsung ke root repository.
3. Beri pesan commit: "Release v1.8.2: audit search relevance, map calibration, clean UI & rich story cards"
4. Klik Commit Changes.
