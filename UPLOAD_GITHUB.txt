PANDUAN UPLOAD GITHUB - ALFA HISTORY WEB (VERSI 1.10.0)
================================================================================

Folder ini (Alfa-Deploy/alfa-siap-upload-v1.10.0) adalah kandidat rilis versi 1.10.0
yang hanya memuat berkas web statis untuk repositori GitHub (alfahistory.web.id).
Seluruh aset gambar baru telah diunggah langsung ke Supabase Storage (bucket `media`,
awalan jalur `v1.10.0/`), dan pembaruan artikel/karakter akan diunggah ke database
Supabase setelah tinjauan dan persetujuan pengguna.

DAFTAR BERKAS WEB YANG DIPERBARUI / DITAMBAHKAN DI v1.10.0:

- detail.html               -> [DIPERBARUI] Penyelarasan i18n header/tombol serta judul bagian tokoh/peristiwa tanpa simbol hias

- i18n.js                   -> [DIPERBARUI] Perbaikan navTimeline ("Timeline"), ALFA_AR_NORM/normalizeDomArabic, alias karakter, peran trilingual di HISTORICAL_GRAPH, penghapusan relasi 605 Abu Bakar & kartu Ummahatul Mukminin, serta perbaikan URL Shamela.ws (Siyar 10906) & Archive.org

   repositori GitHub alfahistory.web.id.
