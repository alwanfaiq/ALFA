ALFA | History of Islam - CHANGELOG v1.8.1

v1.8.1 (Patch Revision: Character Portrait Cards + Clean URLs + Canonical Sync + Admin AI Engine + Dropdown Language + Favicon Fix)
- Disiplin Rilis Baru & Versioning Standar:
  * Sesuai aturan versioning repositori (rule #5), seluruh perbaikan dan penyempurnaan dikemas dalam folder terisolasi baru: alfa-siap-upload-v1.8.1 tanpa menimpa v1.8.0.
  * Hanya memuat berkas-berkas esensial yang diperlukan untuk deployment GitHub Pages.
- Sinkronisasi Data Master & Resolusi 2 Halaman Abdul Muthalib:
  * Mengintegrasikan data master Supabase ke defaults.json (48 Tokoh, 125 Peristiwa, 32 Tempat).
  * Menghadirkan sistem Alias Resolver (resolveCharacterName) untuk mengatasi perbedaan ejaan (Abdul Muthalib -> Abdul Muthallib, Abi Thalib -> Abu Thalib bin Abdul Muthallib, Amr bin Ash -> Amru bin Ash, Halimah as-Sa'diyah -> Halimah Assa'diyah, dll.).
  * Seluruh tautan lama maupun variasi ejaan otomatis bermuara pada satu artikel master lengkap berstandar Humanizer-ID dengan Character Turnaround Sheet.
- Kartu Karakter Menampilkan Wajah Asli Tokoh:
  * Bagian '✦ TOKOH DALAM PERISTIWA INI' pada detail.html kini menampilkan foto potret berwajah (WebP cover) dengan bingkai rasio 1:1 dan framing wajah presisi (object-position: center 20%), menggantikan kartu inisial huruf (AM).
- Pembersihan Kartu Timeline di Halaman Utama (index.html):
  * Menghilangkan kotak kartu mini tokoh dari banner linimasa di beranda agar kartu event tetap rapi dan tidak sesak. Informasi ringkas '2 tokoh / 3 tempat' di footer kartu tetap dipertahankan.
- URL Bersih & Elegan (Clean URLs tanpa .html & Query Soup):
  * Menggunakan HTML5 History API (history.replaceState) sehingga bilah alamat peramban menampilkan URL bersih: /figures/abdul-muthallib, /events/570-kelahiran-nabi, /places/makkah.
  * Menambahkan router 404.html ringan untuk GitHub Pages agar reload atau share link URL bersih langsung mengarahkan ke artikel terkait secara mulus.
- Perbaikan BiDi Angka Arab '1000' (Anti-Terbalik):
  * Mengunci elemen header .h-num dengan CSS direction: ltr !important; unicode-bidi: isolate; sehingga simbol '1✦✦✦' tidak lagi terbalik menjadi '✦✦✦ 1' (0001) saat mode bahasa Arab aktif.
- Favicon Transparan & Adaptif (Tanpa Sudut Putih):
  * Menghapus kotak background padat pada favicon.svg sehingga 100% transparan di sudut tab peramban mana pun.
  * Menambahkan CSS media query prefers-color-scheme: berwarna emas bercahaya pada tema gelap, dan berganti siluet obsidian mewah pada tema terang.
- Penyempurnaan Header & Navigasi:
  * Menghapus teks 'Ctrl K' dari tombol pencarian di header agar tampilan lebih minimalis dan lega.
  * Mengubah tombol bahasa menjadi Dropdown Menu (Indonesia, English, العربية) elegan berlatar gelap-emas, ditempatkan persis di sebelah kiri tombol YouTube.
  * Mengganti istilah bahasa Inggris 'Characters' menjadi 'Figures'.
  * Memperbarui susunan menu navigasi desktop dan drawer mobile: Map — Timeline — Figures — Stories.
- Perbaikan Teks Bocor Kode HTML:
  * Memperbaiki logika deteksi HTML pada detail.html (/<[a-z][\s\S]*>/i) sehingga seluruh artikel yang memuat tag HTML langsung dirender sebagai dokumen rapi, bukan kode mentah.
- Pemindahan Konfigurasi AI Gemini ke Halaman Admin (admin.html):
  * Menghapus total formulir input API Key dari modal pencarian publik. Pengunjung publik menikmati pencarian semantik instan tanpa gangguan teknis.
  * Menambahkan tab '✦ AI & Engine' khusus di admin.html untuk menyimpan GEMINI_API_KEY secara privat, memilih model AI (Gemini 2.5 Flash), dan melakukan uji koneksi secara langsung.
